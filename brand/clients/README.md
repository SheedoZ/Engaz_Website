# Client logos

Drop each client logo here, then wire it into the clients section in
`index.html` (search for `id="clients"`).

- SVG preferred; otherwise a transparent PNG at roughly 320x104.
- Name files after the client in lowercase with hyphens, e.g. `acme-medical.svg`.
- Only add a logo once the client has given written consent to appear.

The clients section ships with the `hidden` attribute set. Remove it once at
least a few real logos are in place.
